# ساعت‌شمار مطالعه (TimeGrid)

اپلیکیشن وب پیشرو (PWA) برای ساعت‌شمار و برنامه‌ریزی مطالعه.

## فایل‌های این ریپازیتوری

- `index.html` — کل برنامه (همون فایلی که آپلود کرده بودید، فقط تغییر نام به `index.html`)
- `manifest.json` — تنظیمات PWA (نام، آیکون، رنگ تم)
- `sw.js` — سرویس‌ورکر برای کارکرد آفلاین
- `icon-192.png`, `icon-512.png` — آیکون‌های برنامه (به‌صورت خودکار ساخته شده؛ در صورت تمایل می‌توانید جایگزین کنید)

## نحوه آپلود در گیت‌هاب

1. یک ریپازیتوری جدید بسازید (مثلاً `timegrid`).
2. همه‌ی فایل‌های داخل این پوشه را در ریشه‌ی (root) ریپازیتوری آپلود کنید — نه داخل یک زیرپوشه.
3. به بخش **Settings → Pages** بروید.
4. در قسمت **Source**، شاخه (branch) `main` و پوشه‌ی `/ (root)` را انتخاب کنید و ذخیره کنید.
5. بعد از چند دقیقه، برنامه در آدرسی مثل زیر در دسترس خواهد بود:
   ```
   https://<username>.github.io/<repo-name>/
   ```

## نکته
اگر فایل `index.html` را دوباره ویرایش کردید، نام آیکون‌ها و مسیرهای `manifest.json`/`sw.js` را دست‌نخورده نگه دارید تا PWA درست کار کند.
